# 9.29 — UI: добавлен `{partner_birthday}` в подсказку плейсхолдеров

## Что это

Доделка к 9.28. В редакторе промпта (страница «Промпт воркера») есть
таблица доступных плейсхолдеров — каждый ряд: имя, область (`both` /
`reply-only`), описание. Кнопка-чип копирует имя в буфер. Список
живёт в `PLACEHOLDERS` константой в TSX. После 9.28 на бэке появился
новый плейсхолдер, но в UI-подсказке его не было — оператор не
видел что он доступен.

## Файлы

- `modules/ui_web/src/pages/WorkerPromptPage.tsx` — добавлена строка
  `{partner_birthday}` сразу после `{partner_bio}`, scope `both`.
  Описание форматирует поведение: `"DD.MM"` / `"DD.MM.YYYY"` / пусто.

## Что НЕ сделано

- `prompts/autochat_reply_system.md` и `prompts/autochat_initial_system.md`
  имеют HTML-комментарии-шапки со СТАРЫМ списком плейсхолдеров
  (`{user_system_prompt}`, `{user_initial_prompt}` — этих в free-form
  редакторе с 9.6 нет, заменены на `{worker_name}` / `{partner_*}` /
  `{conversation_history}` / `{messages_count}` / `{days_since_first}`).
  Эти файлы используются как fallback только когда оба per-worker
  промпта пусты, что нормальным потоком не достигается. Чистить их —
  отдельная задача (привести к актуальному списку плейсхолдеров),
  не расширяю scope сейчас.
- Аналогично `docs/autochat.md` секция «Плейсхолдеры» отстала
  на тот же фронт. Тоже отдельным юнитом, когда руки дойдут.
