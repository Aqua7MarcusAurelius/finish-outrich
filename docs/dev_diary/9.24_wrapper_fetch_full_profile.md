# 9.24 — wrapper.fetch_full_profile + EventType для цепочки профиля

## Что это

Первый коммит из 5 в фиче «один раз дотягиваем расширенный профиль
(bio + день рождения) при появлении нового диалога, дальше используем
из БД как плейсхолдеры в промптах».

Этот коммит — только инфра под цепочку: метод во враппере + новые
константы шины. Логику не дёргает никто, пока не будет коммитов 9.26
(history публикует/слушает) и 9.27 (новый модуль `peer_profile`).

## Файлы

- `modules/worker/wrapper.py`:
  - `+ from telethon.tl.functions.users import GetFullUserRequest`
  - Новый метод `TelegramWrapper.fetch_full_profile(user_id) ->
    {bio, birthday}`. Один запрос к Telegram, возвращает голый dict.
    День рождения — `{day, month, year|None}` либо `None` если
    в ответе TG нет. `SessionExpired` — через общий `_guard`, прочие
    ошибки пробрасываются (caller — `peer_profile` — будет их
    логировать и пропускать, bio не критичен).
- `core/events.py`:
  - `Module.PEER_PROFILE = "peer_profile"` — новый модуль (consumer).
  - `EventType.DIALOG_CREATED = "dialog.created"` — публикует history
    при INSERT (не UPDATE) в `dialogs`. Будет слушать `peer_profile`,
    плюс может слушать UI/CRM-export отдельно.
  - `EventType.DIALOG_PROFILE_FETCHED = "dialog.profile.fetched"` —
    публикует `peer_profile` после успешного `fetch_full_profile`,
    слушает history (UPDATE `dialogs.bio`, `birthday_*`).

## Соответствие принципам

- **Любое общение с Telegram — через враппер.** Метод живёт в
  `TelegramWrapper`, никто другой `GetFullUserRequest` не дёргает.
- **Шина — основной канал между модулями.** Под цепочку завели два
  события вместо прямых вызовов между history и peer_profile.
- **Имена в прошедшем времени.** `dialog.created`,
  `dialog.profile.fetched` — соответствуют конвенции из `event_bus.md`.

## Что НЕ сделано в этом коммите

- Миграция схемы `dialogs.birthday` → `birthday_day/month/year` —
  следующий коммит (9.25). Текущая колонка `birthday DATE` не годится:
  у Telegram день рождения может быть без года, а DATE требует год.
- Публикация `dialog.created` из history — коммит 9.26.
- Сам модуль `peer_profile` — коммит 9.27.
- Плейсхолдер `{partner_birthday}` в autochat — коммит 9.28.
