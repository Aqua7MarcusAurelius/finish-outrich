# 9.18 — vite proxy для `/dialog-statuses` (с проколом)

## Симптом

На `/settings` → «Статусы диалогов» — красный ErrorBox
«Не удалось загрузить статусы — `GET /dialog-statuses -> 404`».
Бэк-ручка отвечает корректно при прямом
`curl localhost:8000/dialog-statuses`.

## Что было не так (итог)

В `modules/ui_web/` лежали два файла рядом: `vite.config.ts` (исходник)
и **`vite.config.js`** (старый транспилированный артефакт). Оба
в `.gitignore`, но в реальном репо на диске у разработчика они
существовали (видимо, остались после прогона `tsc`). Vite v6 в
порядке резолва конфига берёт `.js` РАНЬШЕ `.ts`, поэтому добавление
нового proxy-префикса в `.ts` ничего не меняло — vite читал стаpые
правила из `.js`. Тот же эффект объясняет, почему перезапуск
контейнера не помогал: код-то загружался свежий, просто не тот.

## Что сделано

- Удалены локальные артефакты `vite.config.js` и `vite.config.d.ts`
  с диска. В `.gitignore` они и так есть — в коммиты больше не уйдут.
- В `modules/ui_web/vite.config.ts` оставлен один аккуратный
  префикс `/dialog-statuses` рядом с остальными. Колонки выровнены
  пробелами.

## Чего стоила диагностика

Полтора часа подозрений на: дефис в ключе proxy, порядок ключей
(`/dialogs` vs `/dialog-statuses`), регрессию в http-proxy-middleware,
кэш ноды. Сигнал «vite не подцепляет правки даже после полного
recreate контейнера» появился сильно позже, чем должен был — потому
что вместо контроля «какой именно конфиг сейчас активен» я смотрел
только на содержимое .ts.

## Урок на будущее

Если правки `vite.config.ts` не применяются после рестарта — первым
делом проверить, нет ли рядом `vite.config.js`. Они должны быть
в `.gitignore`, но локально могут отсутствовать или, наоборот,
прорасти, и vite их незаметно подменит.

Команда быстрой проверки:
```
ls modules/ui_web/vite.config.*
# должна вернуть только vite.config.ts
```

И если что-то лишнее — `rm` без сожалений.

## Файлы

- `modules/ui_web/vite.config.ts` — добавлен и аккуратно выровнен
  proxy-префикс `/dialog-statuses`.
- `modules/ui_web/vite.config.js` — **удалён локально**
  (в .gitignore, git не видел).
- `modules/ui_web/vite.config.d.ts` — **удалён локально**
  (в .gitignore, git не видел).
