# 10.9 — UI: настройки источника лидов на воркере

**Дата:** 2026-05-17
**Этап:** 10.9

## Что сделано

Открыли оператору первый UI-вход в новый CRM-контур: на странице
"Промт воркера" (`/workers/:id/prompt`) сверху появился блок
"Источник лидов" с двумя селектами и быстрой панелью под партнёрский
CRM.

## Файлы

- **Бэкенд:**
  - `api/routes/accounts.py`: `/accounts` теперь возвращает
    `lead_source` и `target_gender`; новый эндпоинт
    `PATCH /accounts/{id}/lead-settings`
  - `modules/autochat/generation.py`: `PartnerInfo.gender` + новый
    плейсхолдер `{partner_gender}` в `_build_placeholders`; SELECT
    в `_load_partner_info_for_dialog` теперь подтягивает gender
- **UI:**
  - `modules/ui_web/src/types/api.ts`: типы `LeadSource`, `TargetGender`,
    расширенный `Account`, `PartnerCrmHealth`, `LeadEvaluation`
  - `modules/ui_web/src/lib/api.ts`: новые методы — `patchLeadSettings`,
    `partnerCrmHealth`, `partnerCrmPool`, `partnerCrmRefill`,
    `getEvaluation`, `evaluateDialog`, `getEvaluatorPrompt`,
    `saveEvaluatorPrompt` (последние три понадобятся в 10.10/10.11)
  - `modules/ui_web/src/components/settings/LeadSettingsPanel.tsx` — новый
    компонент с двумя селектами + кнопкой "Забрать N лидов сейчас"
  - `modules/ui_web/src/pages/WorkerPromptPage.tsx`: добавил `<LeadSettingsPanel/>`
    в шапку, и плейсхолдер `partner_gender` в справочник

## Что видит оператор

Открыв страницу промтов воркера:

```
┌──────────────────────────────────────────────────────────────────┐
│ Источник лидов                       CRM: подключён · пул 0      │
│                                                                  │
│ Откуда брать лидов        Фильтр пола (для CRM-пула)             │
│ ┌──────────────────────┐  ┌─────────────────────┐                │
│ │ Пул партнёрской CRM  │  │ Женский             │                │
│ └──────────────────────┘  └─────────────────────┘                │
│ Воркер на тике забирает   При подборе из пула берём только        │
│ следующего из пула CRM    подходящих или с неизвестным полом     │
│                                                                  │
│ ────────────────────────────────────────────────────────────     │
│ [50] [↻ Забрать N лидов сейчас]            [Сохранить настройки]│
└──────────────────────────────────────────────────────────────────┘
```

- Селект `target_gender` неактивен пока `lead_source=manual` — нет
  смысла фильтровать когда оператор сам вбивает username.
- Кнопка "Забрать N лидов сейчас" видна только в режиме partner_crm
  и когда модуль сконфигурирован (`.env` содержит токен).
- Бэйдж "пул N" обновляется после refill'а.

## Почему так, а не иначе

**Поместил в WorkerPromptPage, а не в отдельную страницу.** У воркера
уже одна страница настроек (промт), туда же логично положить
"откуда брать лидов". Оператор переходит с карточки воркера →
видит сразу все вкладки настройки в одном месте.

**Бэйдж пула берётся локально (компонент сам дёргает /health).**
Не тянем через хук — он понадобится в одном месте (пока что),
лишний global state нам тут не нужен.

**PATCH `/accounts/{id}/lead-settings`, а не отдельные эндпоинты
для каждого поля.** Хочется одной кнопкой сохранять оба значения,
чтобы UI был чище. Pydantic-схема позволяет передать любое
подмножество — если оператор поменял только пол, lead_source
бэк не трогает.

**`{partner_gender}` добавлен в общий placeholder-набор autochat
(не только evaluator).** Промт-редактор воркера может его теперь
использовать в reply/initial темплейтах — например "учти что
собеседник {partner_gender}". Для manual-лидов будет пустая
строка, что нормально (оператор увидит в превью).

## Проверка

```bash
curl http://localhost:8000/accounts | jq '.[0] | {lead_source, target_gender}'
# {"lead_source": "manual", "target_gender": "any"}

curl -X PATCH http://localhost:8000/accounts/1/lead-settings \
  -H "Content-Type: application/json" \
  -d '{"lead_source": "partner_crm", "target_gender": "female"}'
# {"id": 1, "lead_source": "partner_crm", "target_gender": "female"}
```

В UI — открыть `/workers/{id}/prompt`, увидеть панель сверху, сменить
селекты, нажать "Сохранить настройки". Бэйдж "CRM: подключён ·
пул N" — пингается при загрузке.

## Открытые вопросы

- При переключении воркера на `partner_crm` пул может оказаться
  пустым — пока poller не сработает, лидов нет. Можно вывести
  toast-подсказку "лиды появятся в течение N секунд" — это сделаем
  если оператор запутается. На MVP — кнопка "Забрать сейчас" даёт
  явный быстрый способ.
