# 9.12 — чистка геометрии пузырей в отчёте

## Что сделано

Доводим визуал отчёта по обратной связи: пузыри были «зажаты» друг к
другу и со сплющенным углом смотрелись чужеродно. Привели их к
полному скруглению-капсуле, развели по вертикали и выровняли
аватарки по верху первого пузыря в группе.

## Файлы

- `modules/autochat/report.py` — только блок `_CSS` (правила
  `.row`, `.bubble`, `.bubble::before`).

## Что именно изменилось

1. `border-radius: 20px` у пузыря по всем 4 углам. Раньше нижний угол
   на стороне аватарки был `4px` — «телеграмная» лопата, но без хвоста
   она ни на что не указывала.
2. Хвостики-треугольники (`::before`) убраны полностью. Со скруглённой
   капсулой они выглядели «приклеенными» — лишняя деталь без функции.
3. `align-items: flex-start` на `.row` — аватарка теперь сидит на
   уровне верха первого пузыря (раньше `flex-end` прижимал её к низу,
   у длинного первого сообщения она выглядела «потерянной»).
4. Между разными авторами — `18px` (`.row + .row { margin-top }`),
   между сообщениями одного автора подряд — `3px`. Раньше было `4px`
   на всех переходах + `2px` на цепочках одного автора — переход
   между авторами визуально терялся.
5. Внутри пузыря `padding: 9px 14px 7px` и `line-height: 1.5`
   (раньше `7px 12px 5px` и `1.45`) — больше воздуха внутри.
6. `gap` между аватаркой и пузырём вырос `8px → 10px`.

## Почему так, а не иначе

- Полное скругление без хвоста читается как «современный мессенджер»
  (Discord, Slack, новые версии Telegram desktop). Хвост + скругление
  одного угла — это старая школа, и без обрамляющего фона аватарки
  она не считывается.
- `flex-start` для всей строки, а не только для аватарки, потому что
  бабл может быть многострочным — мы хотим, чтобы он рос вниз от
  аватарки, а не «уезжал вверх».
- Большой `margin-top` именно через `.row + .row` (а не на самой
  `.row`) — иначе первая строка после `date-sep` получила бы лишний
  отступ. Селектор-сосед даёт нужный гэп только при наличии предыдущей
  строки того же уровня.
