# 10.26 — report_delivery: маршрутизация по семейству воркера

**Дата:** 2026-06-10
**Этап:** 10.26

## Что сделано

Поменяли ключ маршрутизации в карте групп: было «имя воркера → группа»
(1:1), стало «**семейство** воркера → группа» (1:N). Семейство — префикс
имени воркера до первого `_` (`SAD_03_RU → SAD`).

## Почему так, а не иначе

**На практике групп — по семействам, а не по воркерам.** Оператор завёл
7 групп (Sad, Joker, Pipito, Kalaw, Aferist, Face, Onton), а воркеров в
каждом семействе много (`SAD_03_RU`, `SAD_04_RU`, … `SAD_10_RU`). Карта
1:1 потребовала бы перечислить все ~40 воркеров и дописывать её на каждого
нового. Маршрутизация по префиксу — одна запись на семейство, новые
воркеры подхватываются сами.

**Префикс = `name.split("_", 1)[0]`.** Имена воркеров идут как
`{СЕМЕЙСТВО}_{NN}_{СТРАНА}` (`KALAW_01_PL`, `AFERIST_01_RU`). Первый сегмент
— семейство. Ключи карты и префикс нормализуем к ВЕРХНЕМУ регистру, чтобы
в `.env` можно было писать как удобно (`SAD` / `sad` — без разницы).

**Ключ карты — код семейства из имени воркера, а НЕ человеческая метка
группы.** Метка группы у оператора может отличаться по написанию
(«Affeireist» против префикса `AFERIST`). Источник правды — префикс
`accounts.name`, как он попадает в имя файла отчёта.
